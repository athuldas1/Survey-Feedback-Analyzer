# Survey Feedback Analyzer 📝

## 📌 About the Project

The Survey Feedback Analyzer is a beginner-friendly Python project that analyzes customer feedback and ratings.

The project uses basic Python concepts to clean written feedback, count specific words, calculate average ratings, identify the longest comment, and find unique words.

## 🎯 Project Objectives

* Store survey feedback using a dictionary of lists.
* Allow users to add new feedback entries.
* Clean text by removing punctuation and extra spaces.
* Count feedbacks containing specific words.
* Calculate the average rating.
* Find the longest feedback comment.
* Identify unique words across all feedbacks.
* Sort feedback entries by rating.

1. Download or clone this repository.
2. Open `survey_feedback_analyzer.py` using VS Code or another Python editor.

4. Enter the number of additional feedbacks you want to add.
5. Enter the requested name, feedback, and rating.
